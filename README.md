# Welcome to the Matrix — but it's a meme

This is a tiny single-page meme site hosted at https://abbasmcheik.github.io.

Theme: red pill, blue bill (yes, the "blue bill" is intentional — it's the impostor cousin of the blue pill and slightly less morally certain).

What this repo is

- A one-page, highly scientific meme experiment in choice architecture.
- Visuals: falling green code, a red pill, a blue bill, and probably too much irony.
- Outcome: either you discover a secret about reality or you laugh very hard. Same difference.

See it live

- Live site: https://abbasmcheik.github.io

How to run locally

1. Clone this repo.
2. Open index.html in your browser (double-click, drag-and-drop, or use carrier pigeons).

Or, if you're fancy and enjoy pretending to be a dev:

- With Python 3: `python -m http.server 8000` then open http://localhost:8000
- With npm: `npx http-server` then open the address it prints.
